Filling the sheet

Use one sheet per semester, with one row per student. The first four columns are Enrollment No, Student Name, Parent Name and Parent Phone. Every column after those is one subject, headed with the subject's name. There is no limit on the number of subjects.

Each subject cell holds that student's attendance and Mid-Sem marks, for example Theory=86,Practical=92,Marks=16.

  • Theory and Practical are attendance percentages.
  • Marks is the Mid-Sem score out of the class's maximum. For a subject out of another total, write it like Marks=18/25 in every row; it passes at the same share as the class's pass mark. Write AB if the student was absent.
  • Leave a part out when there is nothing to enter yet: a theory-only subject has no Practical, and Marks stays out until the Mid-Sem is held.
  • Small differences are fine: ; or new lines between parts, : instead of =, 82%, 16/20, lowercase, and short names such as Th, Pr and Mid.

Save the file as .xlsx or .csv, up to {{ max_upload_mb }} MB. An old .xls file has to be saved as .xlsx first. Before anything is saved, the review page lists every problem with its row number.

Once a class has students, Download pre-filled sheet on the semester page gives you a sheet with their details already in, so you only add the figures.

What each status means

Each student gets one status per semester. The first one that fits applies.

{{ badge("at_risk") }}
Theory or Practical attendance is below the class's threshold (75% unless changed) in at least one subject.
{{ badge("needs_attention") }}
Attendance is fine, but in at least one subject the Mid-Sem score is below the pass mark (7 unless changed) or the student was absent.
{{ badge("doing_well") }}
Neither of the above.
{{ badge("no_data") }}
The student is in the sheet but has no figures yet.

Subjects without Mid-Sem marks yet are judged on attendance alone. You can change the threshold, pass mark and maximum marks for each class in Class settings.

Students marked {{ badge("left") }} or {{ badge("detained") }} stay on record, but they are left out of the tiles and are not messaged.

Sending messages

  1. Open WhatsApp Web in this browser and sign in with the number shown as Sending as in the top bar. The app can't choose the account: WhatsApp sends from whichever one is signed in.
  2. On a semester page, click a student's name, or use Message pending parents to go through every parent still waiting for a message.
  3. Check the preview: each part is in English, then Gujarati. You can add a short note.
  4. Select Send on WhatsApp. On a laptop, a WhatsApp Web tab opens with the message filled in; on a phone, select Open WhatsApp to open the app. Press send there. If the browser blocks the tab, an Open WhatsApp button appears instead.

The app marks the parent as sent when you select Send on WhatsApp, and it keeps the exact text it prepared. If you then don't send it in WhatsApp, the parent still shows as sent. Skip moves on without a message.

A new sheet for the semester puts every parent back on the pending list, because the figures have changed.

Why sending is paced

WhatsApp can restrict a personal number that sends many messages in a short time to people who haven't saved it. To protect your number, the app spaces messages out:

  • {{ pacing.gap_seconds }} seconds between messages
  • a {{ pacing.burst_pause_minutes }}-minute pause after every {{ pacing.burst_size }} messages
  • at most {{ pacing.daily_limit }} messages a day, across all your classes

These are your current settings. You can change them under Sending safety on your profile. Asking parents to save your number at the start of each semester lowers the risk further.

Changing the message wording

The wording, in English and Gujarati, lives in one text file on the computer that runs the app: message_templates/parent_report.txt.

Ask whoever looks after the app to change them. The next message uses the new wording, with no restart. Parts in double curly brackets, such as {{ "{{ student_name }}" }}, are filled in for each student, so keep them as they are.
